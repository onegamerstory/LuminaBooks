# Решение проблем с белым экраном в Electron

## Проблема: Белый экран при запуске приложения

### Решение 1: Пересборка приложения

После внесенных изменений необходимо пересобрать приложение:

```bash
npm run electron:build
```

Убедитесь, что:
1. Все зависимости установлены: `npm install`
2. Сборка прошла без ошибок
3. Папки `dist/` и `dist-electron/` созданы после сборки

### Решение 2: Проверка консоли разработчика

Если проблема сохраняется:

1. При запуске приложения автоматически откроется DevTools (добавлено для отладки)
2. Или нажмите `F12` / `Ctrl+Shift+I` в окне приложения
3. Проверьте вкладку **Console** на наличие ошибок
4. Проверьте вкладку **Network** - загружаются ли файлы

### Решение 3: Проверка путей к файлам

В консоли разработчика вы должны увидеть логи:
- `Loading production file from: ...`
- `__dirname: ...`
- `app.isPackaged: true`

Если файл не найден, проверьте структуру папок в установленном приложении:
- Windows: `C:\Users\<User>\AppData\Local\Programs\luminabooks\resources\app\`
- Должны быть папки: `dist/` и `dist-electron/`

### Решение 4: Проверка base path

Убедитесь, что в собранном `dist/index.html` все пути относительные (начинаются с `./` или без `/` в начале):

```html
<!-- Правильно -->
<script type="module" src="./assets/index-xxx.js"></script>

<!-- Неправильно -->
<script type="module" src="/assets/index-xxx.js"></script>
```

### Решение 5: Проверка CSP (Content Security Policy)

Если в консоли есть ошибки CSP, возможно нужно настроить политику безопасности в `electron/main.ts`.

### Решение 6: Тестирование без установщика

Соберите приложение без установщика для проверки:

```bash
npm run electron:pack
```

Затем запустите исполняемый файл из папки `release/win-unpacked/LuminaBooks.exe`

### Решение 7: Проверка переменных окружения

Убедитесь, что при сборке не требуется `.env.local` файл (он не должен быть в production сборке, если API ключ не нужен для работы приложения).

## Типичные ошибки и решения

### Ошибка: "Failed to load resource"
- **Причина**: Неправильные пути к файлам
- **Решение**: Убедитесь, что `base: './'` установлен в `vite.config.ts` для production

### Ошибка: "Cannot find module"
- **Причина**: Модули не включены в сборку
- **Решение**: Проверьте, что все зависимости в `package.json` и файлы в `electron-builder` конфигурации

### Ошибка: CORS или CSP
- **Причина**: Политики безопасности блокируют загрузку
- **Решение**: Проверьте настройки `webPreferences` в `electron/main.ts`

## Отладочная информация

При запуске приложения в консоли (терминале) и в DevTools вы увидите:
- Путь к файлу index.html
- Текущий __dirname
- Статус app.isPackaged
- Любые ошибки загрузки

Используйте эту информацию для диагностики проблемы.
