# Инструкция по настройке трея для Windows

## Проблема: Иконка не отображается в системном трее Windows

Если иконка приложения не появляется в области уведомлений Windows (системный трей), это может быть связано с несколькими причинами.

## Решения

### 1. Проверка настроек Windows

Windows 11 и Windows 10 по умолчанию могут скрывать иконки в системном трее. Чтобы показать иконку:

**Windows 11:**
1. Откройте **Настройки** → **Персонализация** → **Панель задач**
2. Найдите **Область уведомлений** или **Значки области уведомлений**
3. Найдите **LuminaBooks** в списке приложений
4. Включите переключатель для отображения иконки

**Windows 10:**
1. Нажмите правой кнопкой мыши на панель задач
2. Выберите **Параметры панели задач**
3. Найдите **Выберите значки, отображаемые в панели задач**
4. Найдите **LuminaBooks** и включите его
5. Или нажмите **Включение и выключение системных значков** и убедитесь, что системные значки включены

### 2. Проверка размера и формата иконки

Для Windows трея требуются иконки определенного размера:
- **Рекомендуемый размер**: 16x16 пикселей
- **Альтернативный размер**: 32x32 пикселей (для высоких DPI)
- **Формат**: `.ico` (предпочтительно) или `.png`

#### Создание .ico файла для Windows

1. Создайте иконку размером 16x16 или 32x32 пикселя
2. Сохраните как PNG
3. Конвертируйте в .ico используя:
   - Онлайн-конвертер: https://convertio.co/png-ico/
   - Или инструмент ImageMagick: `convert icon.png -resize 16x16 icon.ico`
4. Поместите файл в `resources/icon.ico`

### 3. Проверка логов

При запуске приложения проверьте консоль разработчика (если доступна) или логи. Вы должны увидеть сообщения:
- `Loading tray icon from: ...`
- `Original icon size: ...`
- `Tray created successfully`

Если видны ошибки о том, что файл не найден, проверьте, что файл `resources/icon.ico` или `resources/icon.png` существует.

### 4. Пути к иконке в собранном приложении

В собранном приложении пути к ресурсам могут отличаться. Приложение автоматически проверяет следующие пути:

**В production (упакованное приложение):**
- `app.getAppPath()/resources/icon.ico`
- `app.getAppPath()/resources/icon.png`
- `process.resourcesPath/resources/icon.ico`
- `process.resourcesPath/resources/icon.png`

**В development:**
- `resources/icon.ico`
- `resources/icon.png`
- `../../resources/icon.ico`
- `../../resources/icon.png`

### 5. Проверка видимости трея в коде

Убедитесь, что трей создается корректно. В коде есть проверки:
- Проверка существования файла иконки
- Проверка, что иконка загрузилась (не пустая)
- Ресайз до 16x16 для Windows
- Обработка ошибок при создании трея

### 6. Альтернативное решение: Явное отображение иконки

Если иконка все еще не видна, возможно, нужно использовать Windows API для явного отображения. Однако это выходит за рамки стандартного Electron API и требует дополнительных настроек.

### 7. Проверка через уведомления Windows

Попробуйте проверить, что трей работает, даже если иконка не видна:
- Кликните в области уведомлений (где обычно находятся иконки)
- Попробуйте открыть контекстное меню правым кликом
- Проверьте, что при закрытии окна приложение не завершается (значит трей работает)

### 8. Перезапуск проводника Windows

Если ничего не помогает, попробуйте перезапустить проводник Windows:
1. Нажмите `Ctrl+Shift+Esc` для открытия диспетчера задач
2. Найдите **Проводник Windows** (Windows Explorer)
3. Правый клик → **Перезапустить**

### 9. Проверка в режиме разработки vs Production

Проверьте, работает ли трей в режиме разработки:
```bash
npm run electron:dev
```

Если в dev режиме работает, а в production нет, проблема может быть в путях к ресурсам при сборке.

## Отладка

Для отладки добавьте больше логов в `electron/main.ts`:

```typescript
console.log('__dirname:', __dirname);
console.log('app.getAppPath():', app.getAppPath());
console.log('process.resourcesPath:', process.resourcesPath);
console.log('app.isPackaged:', app.isPackaged);
```

Это поможет понять, какие пути используются в вашей системе.

## Рекомендации

1. **Всегда используйте .ico файл для Windows** - это нативный формат Windows
2. **Создайте иконку размером 16x16 пикселей** - стандартный размер для Windows трея
3. **Убедитесь, что файл включен в сборку** - проверьте, что `resources/icon.ico` указан в `package.json` → `files`
4. **Проверьте настройки Windows** - возможно, иконка просто скрыта

## Дополнительная информация

Если проблема сохраняется после всех проверок:
- Проверьте версию Electron: `npm list electron`
- Проверьте версию Windows
- Проверьте настройки приватности Windows (некоторые настройки могут блокировать системный трей)
