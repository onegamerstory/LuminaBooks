# Инструкция по созданию иконки для macOS

## Проблема с растягиванием иконки на macOS

Если иконка растягивается в меню-баре (menu bar) macOS при подключении внешнего монитора, это обычно связано с тем, что файл `.icns` не содержит всех необходимых размеров для разных DPI (Retina и не-Retina дисплеи).

## Требуемые размеры для .icns файла

Для правильной работы иконки на macOS (включая внешние мониторы с разными DPI) файл `.icns` должен содержать следующие размеры:

### Обязательные размеры:
- **16x16** @1x (16x16 пикселей)
- **16x16** @2x (32x32 пикселей) - для Retina дисплеев
- **32x32** @1x (32x32 пикселей)
- **32x32** @2x (64x64 пикселей) - для Retina дисплеев
- **128x128** @1x (128x128 пикселей)
- **128x128** @2x (256x256 пикселей) - для Retina дисплеев
- **256x256** @1x (256x256 пикселей)
- **256x256** @2x (512x512 пикселей) - для Retina дисплеев
- **512x512** @1x (512x512 пикселей)
- **512x512** @2x (1024x1024 пикселей) - для Retina дисплеев

## Как создать правильный .icns файл

### Вариант 1: Использование iconutil (только macOS)

1. Создайте папку `icon.iconset`:
```bash
mkdir icon.iconset
```

2. Поместите все необходимые размеры в папку с правильными именами:
```
icon.iconset/
├── icon_16x16.png       (16x16 пикселей)
├── icon_16x16@2x.png    (32x32 пикселей)
├── icon_32x32.png       (32x32 пикселей)
├── icon_32x32@2x.png    (64x64 пикселей)
├── icon_128x128.png     (128x128 пикселей)
├── icon_128x128@2x.png  (256x256 пикселей)
├── icon_256x256.png     (256x256 пикселей)
├── icon_256x256@2x.png  (512x512 пикселей)
├── icon_512x512.png     (512x512 пикселей)
└── icon_512x512@2x.png  (1024x1024 пикселей)
```

3. Конвертируйте в .icns:
```bash
iconutil -c icns icon.iconset -o icon.icns
```

### Вариант 2: Использование онлайн-конвертеров

1. Используйте онлайн-конвертер, который поддерживает все размеры:
   - https://cloudconvert.com/png-to-icns
   - https://www.icnsconverter.com/
   - https://iconverticons.com/

2. Загрузите исходное изображение (желательно 1024x1024 или больше)

3. Убедитесь, что конвертер создает все необходимые размеры

### Вариант 3: Использование imagemagick (если установлен)

```bash
# Создайте папку для иконок
mkdir -p icon.iconset

# Создайте все необходимые размеры из исходного изображения (icon.png должен быть минимум 1024x1024)
convert icon.png -resize 16x16 icon.iconset/icon_16x16.png
convert icon.png -resize 32x32 icon.iconset/icon_16x16@2x.png
convert icon.png -resize 32x32 icon.iconset/icon_32x32.png
convert icon.png -resize 64x64 icon.iconset/icon_32x32@2x.png
convert icon.png -resize 128x128 icon.iconset/icon_128x128.png
convert icon.png -resize 256x256 icon.iconset/icon_128x128@2x.png
convert icon.png -resize 256x256 icon.iconset/icon_256x256.png
convert icon.png -resize 512x512 icon.iconset/icon_256x256@2x.png
convert icon.png -resize 512x512 icon.iconset/icon_512x512.png
convert icon.png -resize 1024x1024 icon.iconset/icon_512x512@2x.png

# Конвертируйте в .icns (только на macOS)
iconutil -c icns icon.iconset -o icon.icns
```

## Проверка .icns файла

Чтобы проверить, содержит ли ваш .icns файл все необходимые размеры:

1. На macOS: Дважды кликните на файл .icns - он откроется в Preview
2. Проверьте, что все размеры присутствуют (16x16, 32x32, 128x128, 256x256, 512x512, 1024x1024)

Или используйте команду (на macOS):
```bash
iconutil --generate iconset icon.icns --output temp.iconset
ls -la temp.iconset
rm -rf temp.iconset
```

## Минимальные требования для предотвращения растягивания

Если у вас нет доступа к macOS для создания .icns файла, используйте исходное изображение размером минимум **1024x1024 пикселей**. Electron-builder автоматически создаст все необходимые размеры, но качество может быть хуже, чем при ручном создании.

## Рекомендации по дизайну иконки

1. **Размер исходного файла**: Минимум 1024x1024 пикселей, лучше 2048x2048
2. **Формат**: PNG с прозрачностью (alpha channel)
3. **Цвета**: Используйте яркие, контрастные цвета
4. **Детали**: На маленьких размерах (16x16, 32x32) иконка должна быть читаемой
5. **Фон**: Прозрачный фон работает лучше всего

## Размещение иконки

После создания .icns файла, поместите его в папку `resources/`:
```
resources/
└── icon.icns
```

Убедитесь, что в `package.json` указан правильный путь:
```json
"mac": {
  "icon": "resources/icon.icns"
}
```

## Решение проблемы с растягиванием

Если иконка все еще растягивается:

1. Убедитесь, что .icns файл содержит все размеры (особенно @2x версии)
2. Пересоберите приложение после замены иконки
3. Удалите старую версию приложения и установите заново
4. Перезагрузите macOS (иногда система кеширует старые иконки)
