# Инструкция по созданию иконки трея для macOS

## Иконка трея для macOS меню-бара

Для macOS иконка трея должна быть специального формата - **Template Image**. Это монохромная иконка, которая автоматически адаптируется к теме macOS (светлая/темная).

## Требования к иконке трея для macOS

### Формат Template Image

Template Image - это монохромная PNG иконка с прозрачностью, где:
- **Черные области** будут отображаться как черные в светлой теме и белые в темной теме
- **Белые области** будут отображаться как белые в светлой теме и черные в темной теме
- **Прозрачные области** остаются прозрачными

### Размеры

- **22x22 пикселя** @2x (для Retina дисплеев) - рекомендуется
- **16x16 пикселей** @1x (для обычных дисплеев) - минимальный размер

Или используйте **44x44 пикселя** (22x22 @2x) - Electron автоматически масштабирует для разных дисплеев.

### Дизайн иконки

1. **Простота**: Иконка должна быть простой и узнаваемой в маленьком размере
2. **Монохромность**: Используйте только черный и белый цвета (или оттенки серого)
3. **Контраст**: Убедитесь, что иконка хорошо видна на светлом и темном фоне
4. **Прозрачность**: Используйте прозрачный фон

## Как создать иконку трея

### Вариант 1: Создание из существующей иконки

1. Возьмите вашу основную иконку приложения
2. Конвертируйте в монохромное изображение (черно-белое)
3. Упростите детали (уберите мелкие элементы)
4. Измените размер до 22x22 или 44x44 пикселей
5. Сохраните как PNG с прозрачностью

### Вариант 2: Использование графического редактора

1. Создайте новое изображение размером 44x44 пикселя (для Retina)
2. Используйте только черный цвет (#000000) на прозрачном фоне
3. Нарисуйте простую, узнаваемую иконку
4. Сохраните как PNG с прозрачностью

### Вариант 3: Автоматическое создание (если есть исходная иконка)

Если у вас есть исходная цветная иконка, вы можете использовать ImageMagick для создания монохромной версии:

```bash
# Конвертация в монохромное изображение
convert icon.png -colorspace Gray -threshold 50% -resize 44x44 trayTemplate.png
```

Или используйте онлайн-конвертеры для создания монохромной версии.

## Размещение иконки

Поместите созданную иконку в папку `resources/` с именем `trayTemplate.png`:

```
resources/
├── icon.icns          (основная иконка приложения)
├── icon.ico           (для Windows)
├── icon.png           (для Linux)
└── trayTemplate.png   (иконка трея для macOS) ⬅️ НОВЫЙ ФАЙЛ
```

## Проверка иконки

1. Убедитесь, что файл существует: `resources/trayTemplate.png`
2. Проверьте размер: должен быть 22x22 или 44x44 пикселя
3. Проверьте формат: PNG с прозрачностью
4. Проверьте цвета: только черный/белый/серый

## Если иконка не создана

Если файл `trayTemplate.png` отсутствует, приложение автоматически будет использовать основную иконку (`icon.png`), но она может выглядеть не очень хорошо в меню-баре macOS, так как не будет адаптироваться к теме.

## Примеры хороших иконок трея для macOS

- Простая книга (силуэт)
- Буква "L" (для LuminaBooks)
- Открытая книга
- Закладка
- Простой значок библиотеки
