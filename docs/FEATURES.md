# Функциональные возможности LuminaBooks

> Полное описание всех функций приложения, от каталога до синхронизации.

---

## 1. Каталог книг (CatalogView)

### 1.1 Режимы просмотра

- **Сетка (Large grid):** карточки книг с обложками, прогресс-баром, статусом и рейтингом
- **Таблица (Table):** строки с колонками: обложка, название, автор, статус, рейтинг, даты, действия
- Режим сохраняется в `localStorage('lumina_catalog_viewmode')`

### 1.2 Поиск

- Фильтрация книг в реальном времени по названию или автору
- Регистронезависимый поиск (используется `toLowerCase()`)
- Мгновенное обновление результатов при вводе

### 1.3 Фильтры

- **По статусу:** множественный выбор (READING, READ, WANT_TO_READ, ABANDONED, POSTPONED)
- **По рейтингу:** от минимального значения
- Фильтры сохраняются в `localStorage`

### 1.4 Сортировка (только в табличном режиме)

- По рейтингу (возрастание/убывание)
- По названию (А-Я / Я-А)
- По статусу
- По количеству страниц
- Настройка сортировки сохраняется в `localStorage`

### 1.5 Действия с книгами

- **Добавить книгу** — открывает BookModal
- **Редактировать** — открывает BookModal с заполненными полями
- **Удалить** — запрос подтверждения (ConfirmationModal)
- **Добавить в очередь** — для книг со статусом WANT_TO_READ (см. раздел 3)
- **Экспорт JSON** — скачивание всех данных
- **Импорт JSON** — загрузка из файла

### 1.6 Пустое состояние (EmptyState)

- Отображается, когда в библиотеке нет книг или ни одна не соответствует фильтрам
- Содержит призыв добавить первую книгу

## 2. Управление книгами (BookModal)

### 2.1 Форма добавления/редактирования

- **Название** (обязательное поле)
- **Автор** (обязательное поле)
- **Год издания**
- **URL обложки** + превью изображения
- **Статус:** выпадающий список из 5 статусов
- **Оценка:** 0–10 (шаг 1)
- **Дата начала** (DateInput)
- **Дата окончания** (DateInput)
- **Описание/заметки**
- **Всего страниц** (NumberInput)
- **Признак цикла** (isPartOfSeries)
- **Коллекция** — выбор из существующих (FranchiseSelectModal) или создание новой

### 2.2 Google Books API

- Поиск книг по названию через Google Books API
- Требуется API-ключ (настраивается в профиле)
- Результаты поиска заполняют форму автоматически
- Найденные книги кешируются в `books_dictionary`

### 2.3 Локальный словарь книг

- Автодополнение названия и автора при вводе
- Поиск по `books_dictionary` (LIKE COLLATE NOCASE, лимит 10)
- Результаты кешируются из Google Books API и предыдущих поисков

### 2.4 Авто-заполнение дат

- При выборе статуса READING → устанавливается сегодняшняя дата как startDate (если не указана)
- При выборе статуса READ → устанавливается сегодняшняя дата как endDate (если не указана)

### 2.5 Привязка к коллекциям

- **FranchiseSelectModal:** выбор одной или нескольких коллекций из существующих
- Возможность создать новую коллекцию прямо из модального окна
- Синхронизация bookIds в обе стороны

### 2.6 Оценка после прочтения (BookRatingModal)

- Автоматически открывается, когда статус книги становится READ
- Предлагает поставить оценку, если она ещё не установлена (rating === 0)
- Можно отложить (закрыть) или поставить оценку сразу

## 3. Отслеживание чтения (ReadingView)

### 3.1 Очередь (Queue)

- **Карусель** книг со статусом WANT_TO_READ и флагом `inQueue=true`
- Горизонтальная прокрутка с кнопками ChevronLeft/ChevronRight
- Кнопка «Начать чтение» — меняет статус на READING, создаёт startDate
- Кнопка «Убрать из очереди» — снимает флаг `inQueue`
- Отображение пустого состояния, когда нет книг

### 3.2 Сейчас читаю (Currently Reading)

- Карточки книг со статусом READING
- **Таймер-секундомер:** Play/Pause, отображение прошедшего времени
- **Хоткеи:** Space — пауза/продолжить, F — завершить сессию
- Прогресс-бар с процентом прочтения
- Кнопка «Завершить чтение» — создаёт сессию, обновляет прогресс
- Кнопка «Отложить» — меняет статус на POSTPONED
- Кнопка «Бросить» — меняет статус на ABANDONED

### 3.3 Отложенные (Postponed)

- Список книг со статусом POSTPONED
- Кнопка «Читать» — меняет статус обратно на READING, создаёт новую сессию в истории
- Кнопка «Бросить» — меняет статус на ABANDONED

### 3.4 Сессии чтения

Каждая книга может иметь историю сессий чтения:

- **Ручное добавление:** дата, длительность (часы:минуты), начальная/конечная страница, начальный/конечный процент
- **Автоматическое создание:** таймер-секундомер создаёт сессию при завершении
- **Таблица сессий:** дата, время, длительность, страницы, проценты
- **Кнопка удаления** сессии

### 3.5 Автоматическое обновление прогресса

- При завершении сессии обновляется `currentPage` и/или `currentPercentage`
- При достижении 100% статус автоматически меняется на READ
- При завершении сессии на POSTPONED книге — статус меняется на READING (автоматически)

### 3.6 Статистика чтения на карточке

- Общее количество часов, проведённых за чтением книги
- Среднее количество страниц/процентов за сессию

## 4. Коллекции (FranchiseView)

### 4.1 Создание/редактирование (FranchiseModal)

- **Название** (обязательное)
- **Описание**
- **URL обложки** коллекции
- **Выбор книг** из библиотеки для включения в коллекцию

### 4.2 Просмотр коллекций

- **Сетка карточек**, до 3 книг превью с наложением
- Если книг больше 3 — отображается бейдж `+N`
- Отображение количества книг в коллекции
- Поиск по коллекциям

### 4.3 Управление

- Редактирование коллекции
- Удаление коллекции (с подтверждением)
- Книги не удаляются при удалении коллекции — только разрывается связь

### 4.4 Связь книг с коллекциями

- Реализована через `franchiseIds` в объекте книги и `bookIds` в объекте коллекции
- При добавлении/удалении книги из коллекции обновляются оба массива
- При удалении книги из библиотеки — она автоматически удаляется из `bookIds` всех коллекций

## 5. Календарь чтения (CalendarView)

### 5.1 Режимы отображения

- **Фазы чтения (Phases):** отображает диапазоны дат от startDate до endDate для каждой книги
- **Сессии чтения (Sessions):** отображает дни, в которые были сессии чтения

### 5.2 GitHub-стиль тепловая карта (GitHubCalendar)

- Ячейки по дням, цветовая интенсивность в зависимости от длительности чтения
- Навигация по месяцам (ChevronLeft/ChevronRight)
- Быстрая навигация по годам

### 5.3 Взаимодействие

- **Правый клик (context menu) по ячейке** → начать чтение книги в этот день
- Открывается меню выбора книги из библиотеки
- При выборе устанавливается startDate на выбранную дату

### 5.4 Боковая панель статистики (за месяц)

- Количество прочитанных книг
- Количество проведённых за чтением часов
- Самая длинная серия (streak)

---

## 6. Статистика и профиль (StatisticsView)

### 6.1 Общая статистика

- **Всего книг** в библиотеке
- **Прочитано книг** (статус READ)
- **Всего часов** чтения (сумма duration всех сессий)
- **Дней чтения** (количество уникальных дней с сессиями)
- **Самая длинная серия** (max streak consecutive days)

### 6.2 Рейтинги

- **Книги с максимальной оценкой** (top-5)
- **Книги с минимальной оценкой** (bottom-5)

### 6.3 Средняя скорость

- Среднее количество часов на книгу
- Рассчитывается как `totalHours / readCount`

### 6.4 Календарь активности

- Компонент GitHubCalendar с цветовой индикацией по дням
- Отображает активность чтения за выбранный месяц

### 6.5 Селектор месяца

- Выбор месяца и года для просмотра статистики
- Статистика пересчитывается для выбранного периода

## 7. Достижения (Achievements)

### 7.1 Список достижений

| # | ID | Название (RU) | Условие разблокировки |
|---|---|---|---|
| 1 | `'1'` | Начало пути | Прочитайте 1 книгу |
| 2 | `'2'` | Книжный червь | Прочитайте 5 книг |
| 3 | `'3'` | Заядлый читатель | Прочитайте 15 книг |
| 4 | `'4'` | Библиофил | Прочитайте 30 книг |
| 5 | `'5'` | Книжный маньяк | Прочитайте 50 книг |
| 6 | `'6'` | 100 часов | Проведите 100 часов за чтением |
| 7 | `'7'` | Книжный странник | Проведите 500 часов за чтением |
| 8 | `'8'` | Ценитель | Поставьте книге оценку 10 |
| 9 | `'9'` | Коллекционер | Начните читать книги из цикла |
| 10 | `'10'` | Постоянный читатель | Читайте книги в течение 6 разных месяцев |

### 7.2 Система уведомлений (AchievementNotification)

- **Очередь:** при множественной разблокировке показывается по одному
- Каждое уведомление отображается 6 секунд
- Прогресс-бар, показывающий оставшееся время
- Кнопка закрытия (свайп вправо при закрытии)
- Анимация появления/исчезновения
- Фоновое изображение достижения (PNG иконки)

### 7.3 Персистентность

- Разблокированные достижения сохраняются в профиле (SQLite или localStorage)
- При синхронизации с другим устройством достижения объединяются
- Достижения, уже полученные на другом устройстве, не показываются повторно

### 7.4 Проверка достижений

- Запускается при каждом изменении массива книг (`useEffect` на `books`)
- Сравнивает текущие условия с уже разблокированными (Set в ref)
- Не показывает уже показанные достижения повторно

## 9. Синхронизация данных

### 9.1 Режимы (3 шт.)

| Режим | Как включается | Механизм |
|---|---|---|
| IPC (Electron) | Автоматически, если `window.electronAPI?.db` | IPC invoke → SQLite |
| HTTP API | Автоматически, если доступен `/api/status` | fetch → Express → SQLite |
| LocalStorage | Fallback, если нет ни IPC, ни HTTP | JSON в localStorage |

### 9.2 Автосинхронизация

- **Интервал:** каждые 30 секунд
- **Триггеры:** фокус окна `window.addEventListener('focus')`, `visibilitychange → visible`
- **Отключение:** переключатель `autoSync` в настройках профиля

### 9.3 Ручная синхронизация

- Кнопка синхронизации в интерфейсе
- Показывает спиннер во время загрузки
- Уведомление об успехе или ошибке

### 9.4 Миграция localStorage → SQLite

- Однократная автоматическая миграция при первом запуске в Electron
- Переносит `lumina_books_v1` и `lumina_franchises_v1`
- Устанавливает флаг `lumina_migrated`

### 9.5 Архитектура Express-сервера

- Порт: 3456
- Интерфейс: `0.0.0.0` (все сетевые)
- CORS: `*`
- JSON body limit: 10MB
- Раздача статики в production (dist/)

## 13. Обработка ошибок

### 13.1 Error Boundary

- Компонент `<ErrorBoundary>` оборачивает всё приложение
- При ошибке рендеринга отображает сообщение с кнопкой перезагрузки

### 13.2 Ошибки загрузки обложек

- `handleCoverError()` — при ошибке загрузки изображения обложки показывает заглушку
- Применяется ко всем `<img>` с обложками

### 13.3 Ошибки синхронизации

- Все HTTP-запросы обёрнуты в try/catch
- При ошибке показывается Toast-уведомление
- Серверный лог ошибок через `console.error`

### 13.4 Unhandled ошибки (Electron)

- `process.on('uncaughtException')` — логирование
- `process.on('unhandledRejection')` — логирование
