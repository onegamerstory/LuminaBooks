# MCP Servers

В проекте настроены MCP-серверы для opencode. Они доступны агенту автоматически.

## codegraph

`@colbymchenry/codegraph` — предварительно проиндексированный граф кода.

**Используй вместо grep/read** для вопросов о структуре кода:

- `symbol_search` — найти символ (функцию, класс, компонент)
- `get_callers` / `get_callees` — кто вызывает / кого вызывает
- `get_dependency_graph` — граф зависимостей модуля
- `analyze_impact` — анализ влияния изменений
- `find_dead_imports` — мёртвые импорты
- `find_circular_deps` — циклические зависимости
- `get_edit_context` — контекст для безопасного редактирования

**Важно:** после первого клонирования проекта выполни:

```bash
npx -y @colbymchenry/codegraph init -i
```

Это создаст индекс `.codegraph/`. Если индекс устарел (например, после git pull):

```bash
npx -y @colbymchenry/codegraph index
```

**Правила работы:**
1. Доверяй результатам codegraph — не перепроверяй через grep
2. Для обзора незнакомой области используй `get_dependency_graph` или `symbol_search`
3. Для поиска всех мест вызова — `get_callers`
4. После редактирования индекс может быть устаревшим до следующей реиндексации

## sequential-thinking

`@modelcontextprotocol/server-sequential-thinking` — структурированное пошаговое мышление.

**Используй для:**
- архитектурных решений (дизайн API, выбор библиотеки)
- сложного дебага с множеством возможных причин
- многошагового рефакторинга (планирование порядка операций)
- анализа trade-off (напр. SQLite vs PostgreSQL)

Агент сам решает, когда вызывать этот инструмент.

## memories

`@memories.sh/cli serve` — постоянная память для сессий.

**Возможности:**
- `memory_store` — сохранить факт/решение
- `memory_get` — получить сохранённое
- `memory_search` — поиск по памяти
- `memory_context` — контекст текущей задачи

**Используй для:**
- сохранения архитектурных решений и их обоснования
- записи conventions проекта (стиль кода, паттерны)
- запоминания настроек окружения
- передачи контекста между сессиями

**Рекомендуется** также запустить `memories init`, чтобы создать базовую структуру:

```bash
npx -y @memories.sh/cli init
```

## filesystem

`@modelcontextprotocol/server-filesystem` — безопасный доступ к файловой системе.

**Возможности:**
- чтение и запись файлов
- поиск файлов по паттернам
- создание/копирование/перемещение/удаление файлов
- получение метаданных файлов

**Ограничен областью:** только `/Users/ed/GitHub/LuminaBooks` и вложенные директории.

**Используй вместо bash** для операций с файлами, когда нужен безопасный доступ без риска выйти за пределы проекта. В отличие от bash, сервер не позволяет выполнять произвольные команды — только файловые операции в разрешённой директории.
