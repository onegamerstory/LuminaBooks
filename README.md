# LuminaBooks - Персональный Book Tracker

<img width="256" height="256" alt="icon" src="https://github.com/user-attachments/assets/0a18658d-1c10-4e8f-8d04-fdbc83c21023" />

ПК-приложение для отслеживания вашей библиотеки книг, созданное с помощью ИИ на стеке React + Vite + Electron.
Приложение разрабатывалось под себя, опираяясь на то, как нам было бы удобно. 
Ниже кратко будут описаны функциональные возможности.

# Стек и архитектура

- React + Vite + Electron
- Данные профиля и книги со всей информацией сохраняются в БД SQLite на ПК
- Windows-платформа (+ доступ из любого браузера в локальной сети, если запущено основное приложение)
- Нет мобильной версии (ни отдельного приложения, ни браузерной версии)

# Функциональные возможности

- Ведение каталога книг
- Трекинг сессий чтения для каждой книги
- Предложение случайной книги
- Создание коллекций книг
- Экспорт/импорт всех данных в формате JSON
- Настройка обложек по умолчанию
- Настройка авто-синхронизации между несколькими устройствами (пк-версии)
- Вывод статистики за всё время, за конкретный месяц и день
- Два вариант использования: ПК-приложение (базовая версия) и веб-приложение (веб-приложение подключение к базовому по локальной сети)

# ПК-приложение и браузерная версия

## Как это работает?

1. Вы запускаете ПК-приложение на Windows и пользуетесь им как обычным приложением
2. "Под капотом" вместе с этим запускается сервер, который позволяет нам подключиться к этому ПК через браузер
3. Берете, например, macbook и, находясь в той же сети, в браузере переходите по ссылке, указанной в меню приложения

# Сборка Desktop приложения из исходников

## Установка пакетов

```bash
npm install
```

## Режим разработки

```bash
npm run electron:dev
```

Это запустит Vite dev server и Electron одновременно.

## Сборка для Windows

```bash
npm run electron:build
```

Создаст установочный файл `.exe` в папке `release/`.
